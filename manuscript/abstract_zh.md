## 题目

**长程时间关联生长模拟中的噪声发生器偏差，及弹道沉积临界时间关联指数的测定**

## 摘要

生长界面在时间上呈幂律关联的噪声驱动下
（$\langle\eta(x,t)\eta(x',t')\rangle\propto\delta_{x,x'}|t-t'|^{2\theta-1}$），
动力学重整化群预言：当 $\theta$ 低于阈值 $\theta_{\rm th}=1/6$ 时恢复普通
Kardar–Parisi–Zhang（KPZ）标度，高于该值则进入长程相。而已发表数值工作的结论
彼此严重矛盾：临界指数从 $\theta_c\to0$（无阈值）到 $\theta_c\simeq0.20$，再到
$\theta_c=0.25\pm0.03$。

本文证明，**上述全部工作所使用的噪声发生器——Mandelbrot 快速分数高斯噪声
（FFGN）——在 $\theta=0$ 处并不连续**。它的归一化时间关联幅度基本与 $\theta$ 无关
（$\theta\to0$ 时 $A_{\rm FFGN}\simeq1.27$），而精确分数高斯噪声的幅度
$2\theta(\theta+\tfrac12)$ 在原点处消失。我们通过增加发生器分量数确认该效应是
**内禀的而非截断假象**（$\theta=0$ 时拟合幅度在 $N=23/32/48$ 下为
$1.3558/1.3559/1.3559$）。因此
$\mathrm{FFGN}(\theta\to0^+)$ 并非白噪声：实测 $C(1)/C(0)=0.195$，且带
$C(\tau)\propto\tau^{-1}$ 长尾，而白噪声要求 $\tau\ge1$ 时 $C(\tau)=0$。

由于模型对噪声作二值化，标定必须在二值化之后进行。将二值化关联函数与精确分数
高斯噪声族拟合，得到整条已发表的 $\theta$ 轴映射为有效值
$\theta_{\rm eff}\ge0.189>\theta_{\rm th}$：**该噪声族根本无法取到短程 KPZ 区**。
在弹道沉积模型本身中，这造成结构序参量 $p_{\rm flat}$ 在 $\theta=0$ 处 **23% 的
不连续跳变**并**反转其 $\theta$ 依赖方向**，同时把粗糙度指数 $\alpha$ 的表观
变化放大**八倍**（FFGN：0.50→0.84；$\theta$ 连续发生器：0.51→0.56，同一
$L=64,128,256$ 窗口）。

用两种使用互不相交信息、各自带零模型标定的无模型诊断方法（基于精确增量概率质量
函数的 Hellinger 距离；建立在去振幅标度与形貌特征空间上的 Isolation Forest
异常检测），我们在**名义 FFGN 单位**下得到
$\theta_c=0.0002\pm0.0007$ 与 $0.0001\pm0.0011$。但需要指出：这一"起测点"**本身就是
发生器的不连续**（$\theta=0$ 参考系综用 i.i.d. 白噪声，而所有 $\theta>0$ 单元用
FFGN），因此它并不是对 $\theta_c$ 的测量。

改用**在 $\theta=0$ 严格为白噪声、且轴上无偏（偏差小于 5%）的谱发生器**后：在
$L=32\dots512$ 范围内，$\alpha$ 在 $\theta\le1/6$ 与 $1/2$ 一致，在 $\theta=0.25$
处仅略高（$0.531\pm0.012$，$2.7\sigma$），到 $\theta=0.4$ 才升至 $0.575\pm0.012$；
而 FFGN 在同名义 $\theta$ 下给出 $0.633$、$0.702$、$0.859$——**偏差大一个数量级**。
更关键的是：由相邻尺度对提取的 $\alpha_{\rm eff}$ 在**修正发生器下随 $L$ 下降趋向
$1/2$**（$\theta=0.20$：$0.598,0.533,0.497,0.491$；$\theta=0.25$：
$0.553,0.561,0.509,0.498$），而 FFGN 在同名义 $\theta$ 下不下降
（$\theta=0.25$：$0.753,0.625,0.754$；$\theta=0.4$：$0.815,0.868,0.888$）。

形貌上的对比同样决定性地反号。$L=256$、$\theta=0.4$ 时：FFGN 把平坦对比例
$p_{\rm flat}$ 从 $0.433$ 压到 **$0.111$**、把谱粗糙度指数 $\alpha_s$ 推到
**$1.049$**（复现了文献报道的刻面化趋势），而修正发生器把 $p_{\rm flat}$ **升高**到
**$0.511$**、$\alpha_s$ 停在 $0.548$；饱和宽度相差 $4.4$ 倍。**所有被用来论证长程相
的标度与形貌特征，在 FFGN 下全部出现，在正确噪声下全部消失或弱一个数量级。**

## 一个必须修正的自我更正：起测点漂移是假象

我们发现并验证了一个会让整类结论失效的陷阱。在样本数匹配的条件下，固定显著性判据
的起测点 $\theta^*(L)$ 在 $L$ 增大 16 倍范围内单调下降（$z\ge3$：
$0.2415,0.2336,0.1710,0.1375,0.0823$），且强制 $\theta_c=0$ 的有限尺度标度塌缩质量
良好（$\chi^2/{\rm dof}=0.75/3$，$p=0.86$）——单看这些会"排除 $1/6$"。

**但这是假象。** 分割零底本身随 $L$ 下降（$L=32$ 时 $0.0109$，$L=512$ 时
$0.0024$，因为每个样本有更多列），所以固定 $z$ 判据必然在 $L$ 增大时移到更小的
$\theta$——**即便物理完全无标度**。匹配 run 数是必要的但不充分，因为 $L$ 依赖来自
**列数**而非 run 数。

**决定性检验是在固定 $\theta$ 下做**：若存在随 $\theta\to0^+$ 增长的交越长度
$\xi_\times(\theta)$，则固定 $\theta$ 时增大 $L$ 应解析出**更多**长程行为，偏离必须
**随 $L$ 增长**。实测：$L=32\dots512$ 范围内，固定 $\theta$ 的 $\Delta H(\theta,L)$
在 $\theta\le0.25$ 时**误差内与 $L$ 无关**，而在 $\theta\ge0.30$ 时**显著为正**——
即交越真实存在，只是在较小 $\theta$ 处其尺度超过 $L\approx512$。所以 $\theta\le0.25$
在可达尺度上没有可测的起测点；上文那条"完美"的标度塌缩追踪的是零底收缩。

## 补充检验：换成精确 fGn 谱滤波器

本文结论唯一可能被推翻的系统误差，是裸幂律滤波器在高 $\theta$ 处关联幅度偏低
（Nyquist 截断），这可能把交越推远、从而伪造出"$\alpha$ 平直"。我们用**精确分数
高斯噪声谱密度**滤波器独立重跑了 $\theta=0$、$0.10$、$1/6$、**$0.20$、$0.25$**、
$0.30$、$0.35$、$0.40$ 与 $L=32\dots512$（40 个单元，同协议同样本数）：

| $\theta$ | FFGN（文献发生器） | 幂律滤波器 | **精确 fGn 滤波器** |
|---|---|---|---|
| 0 | 0.4986 | 0.5062 | 0.5076 |
| 1/6 | 0.6330 | 0.5082 | 0.5089 |
| **0.20** | 0.6855 | 0.5269 | **0.5368** |
| **0.25** | 0.7019 | 0.5311 | **0.5383** |
| 0.40 | 0.8585 | 0.5750 | 0.5724 |

表中每个 $\alpha$ 都是对**独立实现（realization）**做 run bootstrap 得到的标准差，
全网格为 ±0.011–0.015，代表值 ±0.012（实测：精确 fGn 滤波器在
$\theta=0,\ 0.25,\ 0.40$ 处为 $\pm0.0125,\ 0.0117,\ 0.0123$）。
注意这与有限尺寸拟合的参数误差（$\pm0.0016$ 量级）**不是同一个量**，后者约小 8 倍；
正文一律采用 bootstrap 误差。

两种修正滤波器在整个范围内一致到 **0.008** 以内，而 FFGN 高出 **0.16–0.29**。
即该幅度系统误差的影响比 FFGN 偏离小二十倍，**原先的 caveat 就此解除**。

**固定 $\theta$ 检验**（精确滤波器）：$\mathrm{d}\Delta H/\mathrm{d}\ln L$ 在
$\theta=0.10,\ 1/6,\ 0.20,\ 0.25,\ 0.30$ 处为 $-0.0024,\ +0.0011,\ +0.0004,\
-0.0023,\ +0.0048$ —— **$0.20$ 与 $0.25$ 处不显著**（确认 $L$ 无关），而
**$\theta\ge0.30$ 处显著为正**。$\alpha_{\rm eff}$ 也一致趋向 $1/2$：$\theta=0.25$
时精确滤波器给出 $0.531,\ 0.568,\ 0.540,\ 0.499$，而 FFGN 为
$0.753,\ 0.625,\ 0.753$。

这一补充把结论表述得更明确：**交越真实存在且可被检出，但在 $\theta\le0.25$ 处其
尺度大于 512**；文献报道的强偏离只有在使用 FFGN 时才复现。

**因此我们不报告测得的 $\theta_c$。** 在可达尺度上，用关联幅度正确的发生器时
$\theta\le0.25$ 尚未进入交越（固定 $\theta$ 检验在 0.20 与 0.25 处均不显著），
没有起测点可定位；而 $\theta\ge0.30$ 处交越已显著出现。所以交越本身是被检出的，
只是 $\theta\le0.25$ 处其特征尺度大于 512。$\theta_{\rm th}=1/6$ 未被我们测到的任何
东西反驳（在我们能检验的每个 $\theta$ 上都成立），但也未被证实——因为若真存在
$1/6$ 阈值，$\theta>1/6$ 本应在 $L\approx512$ 就显出长程行为，而它只在
$\theta\ge0.30$ 才显出来。要把 $\theta_c$ 钉死，需要在 $L\gtrsim4096$ 上重做固定
$\theta$ 检验，让 $\theta\le0.25$ 的交越进入窗口。

## 主要贡献

1. **发现并定量刻画了一个影响整个子领域的发生器缺陷**：文献所用的 FFGN 在
   $\theta=0$ 处不连续，数值上表现为 $C(1)/C(0)=0.195$ 的关联地板；其关联幅度
   比精确分数高斯噪声在 $\theta=0.005$ 处大 245 倍、在 $1/6$ 处大 3.9 倍。
2. **在二值化后的噪声上完成 $\theta$ 轴标定**（此前无人做过），得到
   FFGN 的加性偏移约 $+0.19$，这是文献结论分歧的直接来源。
3. **给出一个 $\theta$ 连续、在原点严格为白噪声的替代发生器**，并验证其幅度在
   $\theta\lesssim0.25$ 内与精确值吻合到 10% 以内。
4. **系统检验并否证了三个候选分布观测量**（直方图化的 $\Delta h_r$、直方图化的
   高度、以及保留振幅的任何量），并记录了三个可复现的方法学陷阱。
5. **首次模拟 $\theta<0$ 对照**：$\alpha$ 回到 $1/2$，而 $p_{\rm flat}$ 确实改变，
   从而把"噪声变了"与"普适类变了"区分开。
6. **指出并演示了标准起测点定位方法的系统性缺陷**：当检测零底依赖系统尺度时，固定
   显著性判据的越界点会移动，从而伪造出标度塌缩；我们给出**固定 $\theta$ 的尺度
   依赖检验**作为诊断该缺陷的手段。这对同模型类中此前用 Hellinger 距离 + 新奇性
   检测得到的阈值构成直接的方法学批评。
7. **不报告测得的 $\theta_c$**，并明确说明为什么在可达尺度上无法定位它——这本身
   是本文对领域的一个诚实且有用的结论。
