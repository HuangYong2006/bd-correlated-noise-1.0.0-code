Dear Editors,

Please consider “Noise construction and finite-size inference in temporally correlated ballistic deposition” for publication as a Regular Article in Physical Review E.

The manuscript examines how specified driving processes and measurement protocols affect finite-window comparisons in a temporally correlated interface-growth model. It combines validation of the final binary space–time field, an exact covariance calculation for shared-innovation autoregressive inputs, and matched numerical comparisons of three input constructions. The production grid contains 105 parameter cells with 64 independent runs per cell and sizes from 32 to 512.

Both Gaussian spectral filters show increasing finite-size width slopes with temporal correlation. A paired bootstrap uses their common random streams and does not resolve a slope difference at the seven tested parameters. Additional duration controls compare nested observation windows within fixed spectral records. We also show exactly why the nearest-neighbour increment distribution contains only the flat-pair fraction, restricting what a local probability distance can say about spatial roughening.

The contribution is a controlled numerical comparison and a reproducible set of validation and inference checks for correlated growth simulations. It should interest readers studying kinetic roughening, stochastic driving and computational statistical physics. The study does not infer an asymptotic critical temporal parameter or attribute implementation errors to unverified historical codes.

The accompanying repository at https://github.com/HuangYong2006/bd-correlated-noise-1.0.0-code contains the production data, control results, analysis and plotting code, and source hashes. The manuscript and this letter use the same finite-window interpretation throughout.

Thank you for considering the manuscript.
