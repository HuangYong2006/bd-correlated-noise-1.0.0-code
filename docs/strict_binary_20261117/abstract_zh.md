# 中文摘要

二点时间关联完全相同的二元噪声，可以在并行弹道沉积模型中产生不同的界面宽度。本文比较独立符号与平稳的四步奇偶约束输入，两者三阶以内的联合分布完全相同。精确穷举显示，界面宽度在第四步开始分离。在 L=64–512 的模拟中，奇偶约束输入的晚时宽度高出 7%–12%，相邻尺寸有效指数差的区间与零相容。

在 θ=0.25 的长程相关对照中，高斯与均匀创新通过共同的线性滤波器后具有相同的连续协方差，阈值化后却产生不同的二元关联。对二元关联拟合高斯替代输入后，仍能分辨连通四时刻统计的差异，而采样尺度上的界面宽度斜率差尚未分辨。对照结果显示，斜率对小幅协方差扰动、观测时长和谱截断较为敏感。奇偶约束对照在二点时间关联严格匹配的条件下，分离出了高阶时间结构引起的有限尺度界面响应。
