# 有限范围文献定位（2026-10-31）

本轮仅为补充实验定位核对以下原始来源；不是全面查新，不能据此声称首次发现。

- Rodríguez-Fernández et al., Physical Review E110,024104(2024), Fragility of Kardar-Parisi-Zhang universality class in the presence of temporally correlated noise. 官方摘要已核实：不同微观模型在时间关联驱动下的指数表现可能不同。因此仅再说“微观细节重要”不足以建立新意；本轮更具体的问题是保持生长规则不变，定量隔离创新协方差及阈值化过程的影响。来源：https://journals.aps.org/pre/abstract/10.1103/PhysRevE.110.024104
- Manna et al., Nature Communications17,8788(2026), Escape-induced temporally correlated noise driven crossover in growth kinetics and universality class. 2026-07-18发表，已核实出版页摘要。作者将Sn薄膜生长中的跨越与吸附原子逃逸产生的时间关联噪声联系起来。该实验体系与当前离散二值模型不同，不能用本轮噪声对照去重解释其具体实验机制；可用来说明噪声微观来源需要可检验的机制链。来源：https://www.nature.com/articles/s41467-026-75545-0

本轮的潜在增量是可补偿的创新耦合对照，以及在二值输入层面区分二阶相关与高阶统计的证据边界。是否有新物理结论必须由完成后的结果决定，不能由期刊目标反推结论。
