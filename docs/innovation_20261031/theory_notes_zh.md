# 协方差补偿的解析逻辑

令 X_n(t)=r_n X_n(t-1)+z_n(t)，eta(t)=sum_n W_n X_n(t)，创新方差为sigma_z^2。共享创新时Q_nm=sigma_z^2；独立创新时Q_nm=sigma_z^2 delta_nm。对于本文正权重和0<=r_n<1，

C_shared(tau)=sigma_z^2 sum_n A_n r_n^tau,
A_n=W_n sum_m W_m/(1-r_n r_m), tau>=0。

因此取独立模态权重V_n=sqrt((1-r_n^2)A_n)，即可得到C_independent,V(tau)=C_shared,W(tau)。这不是简单方差重标定，而是逐模态调整；所有滞后同时匹配。对称延拓后，完整功率谱相等。在同一离散傅里叶网格采样、共同去除DC后，有限周期协方差仍相等。

高斯输入具有更强的结论：零均值与完整协方差决定所有有限维联合分布；各空间位置独立，故整个时空场的分布相同。逐点阈值和确定性的BD更新不会改变这种分布相等性。因此高斯共享与补偿独立模型的任何界面统计量在分布上都相同。实验比较是实现与有限样本正对照，而不是发现“创新共享本身产生独立物理效应”。

均匀创新不具备该保证。对于对称连续输入，s=2*1[eta>0]-1，有Cs(tau)=4*P(eta_t>0,eta_{t+tau}>0)-1。右侧是二元正交象限概率，不能由非高斯过程的原始协方差单独决定。因此原始协方差相同、二值驱动不同是允许的。实际生长只接收二值场；应将输入差异首先归于阈值后相关结构，不能直接归于“高阶统计导致界面变化”。

二值高斯替代对照采用rho_target=sin(pi*Cs_target/2)，再以非负谱混合拟合，保证构造合法。训练点拟合残差不能代替独立验证；未测滞后的残差也未被消除。即使现有检验通过，界面无显著差别只能报告“在当前精度下未分辨”，而不能证明物理等效；如仍有差别，也只是协方差容差和滞后范围条件下的高阶机制候选证据。

物理解释的可检验链条为：模态交叉项改变有效时间相关形状 -> 阈值沉积的持续事件概率改变 -> 局部坡度/平坦区及空间谱发生响应 -> 有限尺寸宽度及斜率变化。每一箭头需对应测量；只有相同时间指数或两条曲线外观相似不足以完成归因。当前额外保存Cs、持续沉积概率、平坦比例、高度差关联及空间结构因子，供最终结果对照。该链条是待数据检验的解释框架，不是预先写定的新物理结论。

正负整体翻转对称性还意味着所有奇数阶符号矩为零。对连续四个时刻，有16P(++++)=1+3Cs(1)+2Cs(2)+Cs(3)+E[s0s1s2s3]。因此在两点相关已测的情况下，可以用持续四次正沉积概率与短滞后Cs估计独立的四点统计。二值验证归档同时保存这些量，分析报告将给出替代输入相对新参考输入的四点矩差及运行级置信区间。该量只诊断输入高阶结构，不自动证明界面变化的原因。
